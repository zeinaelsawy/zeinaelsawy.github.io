# Zeina Elsawy — Portfolio

**Live site: [https://zeinaelsawy.github.io](https://zeinaelsawy.github.io)**

This is my personal portfolio website. It is for recruiters and anyone who wants to see my work in one place, across the two fields I work in: game and web design, and cybersecurity.

The site is built like a small game. Visitors press start, choose a class, and explore my projects; an XP bar fills as they discover more.

## What's on the site

- **The Designer**: games I have built (Ball Frenzy, Moth to a Flame), a Donkey Kong level, the Toro2 Mokhtalefa board game, the EasyEnroll course planner web app, and my design toolkit.
- **The Defender**: my information security and data privacy experience, security and hardware projects (KRACK attack and fileless malware simulation, RISC-V processor, Tomasulo simulator), and my security toolkit.
- **Save file**: my CV, in a design and web version and a cybersecurity version.
- **Contact**: email, LinkedIn and GitHub.

## About me

I am a final-year student at the American University in Cairo, studying for a B.Sc. in Cybersecurity with a Minor in Game Design, graduating Spring 2027.

## How it's built

A single static page in HTML, CSS and JavaScript with no frameworks or build step, hosted on GitHub Pages.

| Path | Contents |
| --- | --- |
| `index.html` | The whole site: markup, styles and scripts |
| `img/` | Images used on the page |
| `cv/` | Downloadable CVs (PDF) |

To update the site, edit or replace a file and commit to `main`. GitHub Pages republishes it within a minute or two.
